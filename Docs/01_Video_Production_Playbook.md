
# 01_Video_Production_Playbook.md

# Video Production Master Playbook  
## Curso: Desarrollo de Software con IA y Agentes Autónomos bajo Scrum

---

# 1. Objetivo del Playbook

Este documento estandariza la producción audiovisual del curso para garantizar:

- Consistencia entre unidades  
- Calidad profesional premium  
- Eficiencia operativa en grabación y edición  
- Reutilización estratégica de assets  
- Escalabilidad a múltiples instructores  
- Coherencia entre versiones Marketplace, Premium y B2B  

Aplica para:

- Marketplace (Udemy u otras plataformas masivas)
- Plataforma propia (Self-paced + Cohorte Premium)
- Versión Corporativa B2B

---

# 2. Arquitectura de Contenido por Canal

## 2.1 Marketplace (Udemy)

**Objetivo:** Alcance masivo + validación social.

### Características:

- Videos de 8–15 minutos.
- Contenido ligeramente recortado.
- CTA estratégico hacia versión Premium.
- Sin profundizar en casos empresariales internos.
- Sin repositorios privados avanzados.
- Enfoque conceptual + demo ligera.

### Duración recomendada por unidad:
20–30 minutos totales divididos en cápsulas.

---

## 2.2 Plataforma Propia (Premium)

**Objetivo:** Alto margen + posicionamiento profesional avanzado.

### Características:

- Videos de 20–40 minutos.
- Demos completas paso a paso.
- Casos empresariales reales.
- Laboratorios completos.
- Evaluaciones detalladas.
- Recursos descargables (repos, plantillas, ADRs).
- Supervisión real de agentes.

---

## 2.3 B2B Corporativo

**Objetivo:** Formación estratégica empresarial.

### Formato:

- Workshops en vivo.
- Evaluación de equipos técnicos.
- Caso adaptado a contexto real de empresa.
- Reporte de madurez técnica.
- Recomendaciones de adopción IA.

---

# 3. Estructura Estándar de Video

Cada video debe seguir esta estructura narrativa:

| Tiempo | Segmento | Objetivo |
|--------|----------|----------|
| 0:00 | Hook | Impacto inmediato |
| 0:30 | Contexto profesional | Relevancia empresarial |
| 2:00 | Problema real | Caso concreto |
| 4:00 | Marco conceptual | Fundamento técnico |
| 8:00 | Demo técnica | Aplicación práctica |
| 15:00 | Validación y métricas | Evidencia objetiva |
| 20:00 | Cierre estratégico | Reflexión + CTA |

---

# 4. Guía de Grabación

## 4.1 Formato de Cámara

- Plano medio profesional.
- Fondo neutro o técnico.
- Iluminación frontal suave.
- Audio limpio (-12dB promedio).
- Grabación mínima 1080p (ideal 4K).

---

## 4.2 Screen Recording

- Fuente ≥ 18pt.
- Cursor visible.
- Zoom activo.
- Terminal limpia.
- Sin notificaciones.

---

# 5. Control de Calidad Antes de Publicar

Checklist obligatorio:

- [ ] Audio limpio
- [ ] Demo funcional
- [ ] Código probado
- [ ] CI verde visible
- [ ] Sin información sensible
- [ ] Subtítulos revisados

---

# 6. Flujo Operativo de Producción

1. Guion académico aprobado.
2. Script teleprompter generado.
3. Storyboard validado.
4. Grabación.
5. Edición.
6. Revisión técnica.
7. Publicación.

---

# 7. Estándar de Profesionalización

Este curso debe percibirse como:

- Formación ejecutiva.
- Programa técnico avanzado.
- Especialización profesional real.

Nunca como bootcamp básico.
