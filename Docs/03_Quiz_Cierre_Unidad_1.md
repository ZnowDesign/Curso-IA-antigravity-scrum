# Sección 1 – Conceptual (Selección múltiple)

## 1. ¿Cuál es el principal cambio de paradigma en AI-Augmented Engineering?

A) Escribir código más rápido  
B) Delegar sin supervisión  
C) Supervisar estratégicamente la generación de código  
D) Eliminar pruebas automatizadas  

**Respuesta correcta:** C

---

## 2. ¿Qué riesgo existe al usar IA sin validación técnica?

A) Mejora automática del diseño  
B) Reducción de deuda técnica  
C) Deuda técnica acelerada  
D) Mayor modularidad garantizada  

**Respuesta correcta:** C

---

## 3. ¿Cuál NO es un componente obligatorio de un prompt profesional?

A) Contexto técnico  
B) Restricciones claras  
C) Opinión personal  
D) Criterios verificables  

**Respuesta correcta:** C

---

## 4. ¿Qué métrica mínima exige la unidad para validar calidad?

A) 50% coverage  
B) 60% coverage  
C) 70% coverage  
D) 90% coverage  

**Respuesta correcta:** C

---

# Sección 2 – Análisis de Escenario

## 5. Un agente genera una función que cumple parcialmente los criterios pero no incluye pruebas automatizadas.

¿Qué acción es correcta?

A) Aceptar el código y avanzar  
B) Eliminar los criterios  
C) Refinar el prompt y exigir pruebas  
D) Ignorar el coverage  

**Respuesta correcta:** C

---

## 6. El pipeline CI falla pero la funcionalidad parece correcta.

¿Qué decisión profesional corresponde?

A) Ignorar el fallo  
B) Marcar como terminado  
C) Corregir hasta que el CI esté verde  
D) Desactivar el CI  

**Respuesta correcta:** C

---

# Sección 3 – Evaluación de Prompt

## 7. Analiza el siguiente prompt:

“Haz una función para validar usuarios.”

¿Cuál es el problema principal?

A) Es demasiado técnico  
B) Carece de contexto y restricciones  
C) Tiene demasiadas reglas  
D) Está sobre-especificado  

**Respuesta correcta:** B

---

## 8. ¿Cuál es una versión mejorada?

A) “Haz validación.”  
B) “Implementa validación.”  
C) “Implementa validateUser(email, password) en Node.js con Jest, coverage mínimo 70%, sin librerías externas y manejo explícito de errores.”  
D) “Haz algo funcional.”  

**Respuesta correcta:** C
