# Plataforma y Operación
## Modelo Marketplace + Plataforma Propia + B2B

---

# 1. Arquitectura de Entrega por Canal

El modelo operativo está diseñado para maximizar:
- Alcance (Marketplace)
- Margen (Plataforma Propia)
- Ticket alto (B2B Corporativo)

---

## 1.1 Canal 1 – Marketplace (Ej. Udemy)

### Objetivo
- Validación social
- Captación masiva
- Generación de autoridad

### Estrategia de Contenido
- Versión recortada (60–70% del contenido total)
- Sin acceso a cohortes premium
- Sin revisión personalizada de PR
- Proyecto final simplificado

### CTA Estratégico
- Upgrade a cohorte premium
- Acceso a mentoría
- Certificación avanzada
- Acceso a repos privados y evaluaciones profundas

### Estructura
- Videos pregrabados
- Ejercicios descargables
- Evaluación automática básica

---

## 1.2 Canal 2 – Plataforma Propia (Teachable / Kajabi / Web)

### Modalidad Self-Paced
- Acceso completo al contenido
- Laboratorios descargables
- Evaluaciones con rúbrica
- Certificado digital automático

### Modalidad Cohorte Premium
- Sprints reales
- Revisión de Pull Requests
- Capstone evaluado en vivo
- Defensa técnica
- Certificación avanzada

### Diferencial Competitivo
- Supervisión real de agentes
- Feedback estructurado
- Scorecard profesional

---

## 1.3 Canal 3 – B2B Corporativo

### Formato
- Workshop intensivo 2–5 días
- Adaptación a stack empresarial
- Proyecto aplicado a caso real

### Entregables
- Reporte diagnóstico técnico
- Recomendaciones de adopción IA
- Evaluación de madurez AI-Augmented

### Valor Empresarial
- Reducción de deuda técnica
- Mejora control de calidad
- Establecimiento de políticas IA internas

---

# 2. Requerimientos Operativos

## Pagos
- Marketplace: gestionado por plataforma
- Plataforma propia: Stripe / PayPal
- B2B: facturación directa

## Certificados
- Digital PDF con ID único
- Verificación pública en web

## Soporte
- SLA respuesta: ≤48h (self-paced)
- SLA cohorte: ≤24h días hábiles
- B2B: SLA contractual

---

# 3. Estructura de Assets

## Videos
- Microlecciones 8–15 min
- Demos reales grabadas

## Slides
- Formato académico
- Diagramas arquitectónicos

## Repositorios
- Repo base por unidad
- Repo Capstone template

## Plantillas
- ADR
- Prompt template
- Scorecard
- Sprint report

## Evaluaciones
- Diagnóstica
- Formativa por sprint
- Sumativa

---

# 4. Política de Devoluciones (Alto Nivel)

Marketplace:
- Según política oficial plataforma.

Plataforma Propia:
- Garantía 7 días si <20% progreso.

Cohorte Premium:
- No reembolsable tras inicio de Sprint 1.

B2B:
- Condiciones contractuales.

---

# 5. Seguridad y Privacidad

## Datos de Alumnos
- Almacenamiento cifrado.
- Acceso limitado a instructores.

## API Keys
- Nunca compartidas públicamente.
- Uso de variables de entorno.

## Repositorios
- Capstone privado opcional.
- Logs auditables.

## Buenas Prácticas
- No incluir secretos en prompts.
- Revisión manual antes de publicación.
