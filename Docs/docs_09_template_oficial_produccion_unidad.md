---

# 0. Propósito del Template

Este documento define el estándar obligatorio para producir cada unidad del curso con nivel profesional avanzado.

Objetivos del template:
- Garantizar consistencia académica.
- Asegurar aplicabilidad industrial.
- Integrar Scrum + Agentes en cada unidad.
- Evitar contenido superficial.
- Facilitar escalamiento del programa.

Cada unidad debe cumplir este formato antes de grabarse o publicarse.

# 13. Estándar de Calidad Profesional

Una unidad se considera lista si:

- Genera evidencia técnica verificable.
- Integra Scrum y agentes explícitamente.
- Tiene laboratorio reproducible.
- Incluye evaluación clara.
- Puede impartirse sin improvisación.
