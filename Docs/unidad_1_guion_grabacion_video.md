# Guion de Grabación en Video – Unidad 1
## AI-Augmented Engineering: Supervisión Estratégica de Agentes

Duración estimada: 25–35 minutos  
Formato: Clase grabada profesional (Marketplace + Plataforma Premium)

---

# 1. Apertura (Min 0–3)

## Objetivo del segmento
Explicar el cambio de paradigma en ingeniería de software hacia AI-Augmented Engineering.

### Guion sugerido
"En 2025, el desarrollador que sobrevive no es el que escribe más código, sino el que supervisa mejor a los agentes que lo generan."

Puntos clave a mencionar:
- El código dejó de ser el cuello de botella.
- La supervisión técnica es la nueva ventaja competitiva.
- Este curso no enseña a usar IA, enseña a gobernarla.

Visual sugerido:
Slide 1 + comparación Developer 2015 vs AI-Augmented Engineer 2025.

---

# 2. Cambio de Paradigma (Min 3–8)

## Explicación Didáctica
Antes:
- Desarrollo manual línea por línea.
- Validación manual.
- Iteraciones lentas.

Ahora:
- Generación asistida.
- Supervisión estratégica.
- Iteración acelerada con control técnico.

Pregunta para audiencia:
"¿Si un agente puede escribir código más rápido que tú, dónde está ahora tu valor?"

Mensaje clave:
Supervisar > Generar.

---

# 3. Productividad Real vs Falsa Productividad (Min 8–12)

Explicar diferencia entre:
- Código rápido sin pruebas.
- Código con cobertura, CI verde y arquitectura clara.

Mostrar métricas reales:
- Coverage ≥70%.
- Pipeline exitoso.
- ADR documentado.

Frase fuerte para grabación:
"La velocidad sin validación es deuda técnica acelerada."

---

# 4. Introducción al Flujo Antigravity (Min 12–18)

Explicar paso a paso:
1. Plan técnico.
2. Prompt estructurado.
3. Generación.
4. Validación automática.
5. Refactorización.

Demostración sugerida:
Mostrar cómo primero se diseña la función antes de escribir el prompt.

Mensaje clave:
Nunca delegues antes de planificar.

---

# 5. Cómo Escribir un Prompt Profesional (Min 18–23)

Estructura recomendada:
- Contexto técnico.
- Tarea delimitada.
- Restricciones.
- Criterios de aceptación.

Ejemplo en pantalla:
"Implementa función validateUser(email, password) con Jest, cobertura mínima 70%, sin librerías externas."

Explicar por qué incluir restricciones reduce errores.

---

# 6. Mini Demo Supervisada (Min 23–30)

Mostrar:
- Prompt redactado.
- Código generado.
- Revisión crítica.
- Corrección del prompt.
- Mejora del resultado.

Narrativa clave:
"El agente no es el ingeniero. Tú lo eres."

---

# 7. Cierre Estratégico (Min 30–35)

Resumen:
- El nuevo rol es AI Supervisor.
- Productividad real requiere métricas.
- Scrum y CI son obligatorios.

Reflexión final:
"No se trata de cuánto código produces, sino de cuánto valor validado entregas."

Call to Action:
En la siguiente unidad integraremos este enfoque dentro de Scrum formalmente.
