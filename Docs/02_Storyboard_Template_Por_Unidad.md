# Template Oficial de Storyboard por Unidad  
## Curso: Desarrollo de Software con IA y Agentes Autónomos bajo Scrum

---

# 1. Objetivo del Storyboard

El storyboard define visual y operativamente cómo se grabará cada unidad.

Su propósito es:

- Reducir improvisación  
- Evitar regrabaciones  
- Coordinar instructor + editor + diseñador  
- Garantizar ritmo profesional  
- Asegurar coherencia visual en todo el curso  

Este documento debe completarse antes de grabar cualquier unidad.

# 7. Indicaciones para Editor

- Ritmo dinámico
- Evitar silencios largos
- Insertar zoom en código crítico
- Añadir subtítulos técnicos clave
- Mantener consistencia visual

---

# 8. Indicadores de Calidad del Video

Un video cumple estándar premium si:

- No supera 12–15 min por segmento en marketplace
- Tiene demostración real, no simulada
- Muestra evidencia técnica verificable
- No repite información textual de slides
- Incluye reflexión estratégica final
